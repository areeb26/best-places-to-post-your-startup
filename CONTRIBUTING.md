# Contributing

Thanks for helping keep this list useful. The goal is a short list of **reputable** places to post or list a startup, not a list of every directory on the internet.

## How to suggest a site

1. Fork this repository and create a branch.
2. Add one entry to the right category in `README.md`, in alphabetical order.
3. Open a pull request. Fill in the template, including how the site meets the criteria below.
4. Please send one site per pull request, so each one can be reviewed on its own merits.

If you are not sure a site fits, open an issue first and ask.

## Quality criteria

A site is added only if it meets all of these:

- **Real moderation.** Submissions are reviewed by people or held to clear community rules.
- **Real audience.** Users, buyers, investors or readers actually visit and use it. A site that is mainly a backlink source does not qualify.
- **Live and working.** The homepage and the submission page load. Parked, abandoned and 404 pages are rejected.
- **Clear terms.** It is clear whether listing is free, freemium or paid.
- **Safe content.** No gambling, casino or adult listings, and no injected spam links.

## Entry format

```markdown
- [Site Name](https://example.com) - **Free**. One-line description of what it is, plus any approval wait. [Submit](https://example.com/submit) _Links: Nofollow._
```

- Pricing must be one of **Free**, **Freemium** (free tier plus paid options) or **Paid**.
- Keep the note to one factual sentence or two. No marketing language, superlatives you cannot back up, or traffic and DR claims.
- Add the `[Submit](...)` link only when it differs from the homepage.
- Add `_Links: Dofollow._` or `_Links: Nofollow._` only if you have checked it. Otherwise leave it out.
- Use the site's homepage, not an affiliate or referral link.

## What gets rejected

- Sites that sell "DR", backlinks or guaranteed SEO value.
- Badge-swap or link-exchange directories, where a free listing requires a badge or backlink on your site.
- "Submit to 100+ directories" services and meta-lists of directories.
- Pay-for-review blog networks and private blog networks.
- Thin, auto-generated or scraped directories with little original content.
- Sites with gambling, casino or adult content, or spam listings.
- Dead, parked, redirected-away or unreachable sites.
- Duplicates of an existing entry, including sister sites that share the same vendor portal.
- Self-promotion of a directory you own, unless it clearly meets every criterion above. Please disclose any affiliation in your pull request.

Entries can be removed later if a site stops meeting these criteria.
